# FnP Sales Analysis
Sales analysis project created using Microsoft Excel.

## About
This project analyzes sales data to understand:
* Revenue and sales trends
* Product performance
* Customer data
* Sales by occasion
* Delivery performance

## Dataset
* 1,000 Orders
* 100 Customers
* 70 Products
* 301 Locations

## Tools Used
* Microsoft Excel
* Pivot Tables
* Excel Formulas
* Data Analysis
* Dashboard

## Key Insight
The project analyzes sales data and presents the results through an Excel dashboard to support business decision-making.



**Data Analytics | Excel | Business Intelligence**
